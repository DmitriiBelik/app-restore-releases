# App Restore

Бесплатная программа для Mac и Windows: переносит на новый iPhone приложения из истории покупок вашего Apple ID, в том числе удалённые из App Store (СберБанк Онлайн, ВТБ, Альфа-Банк, Т-Банк, VK, MAX и другие). Приложения ставятся по кабелю, без джейлбрейка и сторонних магазинов.

Здесь лежат только установщики. Скачать последнюю версию: [Releases](https://github.com/DmitriiBelik/app-restore-releases/releases/latest).

| Файл | Для какого компьютера |
|---|---|
| `AppRestore-<версия>-mac-arm64.dmg` | Mac на Apple Silicon (M1 и новее) |
| `AppRestore-<версия>-mac-x64.dmg` | Mac на Intel |
| `AppRestore-<версия>-win-x64.exe` | Windows 10 и 11 |

## Первый запуск

Программа выходит без платной подписи Apple и Microsoft, поэтому система один раз предупредит о неизвестном разработчике.

- **macOS:** откройте программу, в окне «Приложение не открыто» нажмите «Готово». Затем «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть» и пароль от Mac.
- **Windows:** в окне «Система Windows защитила ваш компьютер» нажмите «Подробнее» → «Выполнить в любом случае». Для работы с iPhone нужно бесплатное приложение «Устройства Apple» из Microsoft Store или iTunes.

## Безопасность

Пароль от Apple ID уходит только на серверы Apple, напрямую с вашего компьютера. Своих серверов у программы нет, пароль не сохраняется.
